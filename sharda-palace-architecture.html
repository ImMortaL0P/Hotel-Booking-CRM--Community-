Core Infrastructure Stack

The application is decoupled into three heavily optimized layers for speed and reliability.

Built with React.js + Vite + Tailwind CSS. Hosted on Vercel's Edge Network.

Express.js processing engine deployed on Render's efficient cloud instances.

Database (MongoDB Atlas)

Enterprise NoSQL database providing encrypted cloud storage at AWS Mumbai.

  • Strict IP-Allowlisting prevents external hijacking
  • Mongoose strict schemas ensure clean guest metadata
  • Infinite scalability without SQL migration headaches

Backup & Files (Google Cloud)

Integrated Google Drive API acting as a zero-cost immutable file server.

  • Automatically generates branded Invoice PDFs on checkout
  • Synchronous upload to designated CRM drive folder
  • Maintains long-standing financial archives safely

Defense & Server Security

CORS Lockdown

Backend API expressly rejects all queries globally unless the request originates strictly from the certified Vercel Frontend domain. Prevents cross-site API hijacking.

Helmet Protection

Enforces strict HTTP headers to block Clickjacking, Cross-Site Scripting (XSS), and sniffed MIME types directly from the Express middleware.

Rate & Brute-force Limiting

Express-Rate-Limit throttles rogue IP addresses attempting DDoS attacks, locking out abusive traffic automatically to preserve API resources.

The Custom Domain Advantage (shardacrm.in)

For a negligible cost of ₹700/year (~₹58/mo), attaching a custom domain provides a massive strategic edge over SaaS alternatives. Instead of your frontdesk logging into a generic third-party portal (like app.cloudbeds.com/sharda), your entire system operates natively at shardacrm.in. This establishes immediate localized brand authority, shields your internal tech stack from outside vendors, fully prevents "SaaS Lock-in", and unlocks root control for professional corporate email routing. Crucially, this allows all automated guest communications—such as booking confirmations, custom invoices, and pre-arrival emails—to be dispatched directly from a verified address like manager@shardacrm.in instead of a generic public email account, significantly boosting guest trust, deliverability, and overall hotel prestige.

Over a standard 3-year Phase 1 operating period, Sharda Palace retains approximately ₹7,82,000 purely in avoided SaaS/subscription costs, directly bolstering net operational profit while owning completely un-watermarked, independent intellectual property.

Client Deliverable & Handoff Checklist

Structured 5-step operational transfer protocol ensuring the client assumes complete technical isolation.

  1. 1

    Account Abstraction & Domain Association

    We setup official client-owned accounts. The architectural codebase is migrated out of developer sandboxes into the client's official Vercel/Render accounts containing their billing logic and the private shardacrm.in domain.

    Deliverables: Domain verification, DNS TXT and CNAME Records injected for seamless internal routing.
  2. 2

    Secrets Validation & Environment Injection

    Because the code is engineered for SaaS mobility, no database passwords exist in source files. We inject the client's unique MongoDB URIs, JWT signing keys, and Google Drive Service Tokens strictly into the deployment dashboards.

    Protection logic: process.env.MONGODB_URI remains invisible to code-readers.
  3. 3

    Beds24 & Extranet API Approval Handshake

    Client initiates their Booking.com Extranet portal. We route an API access request authorizing Beds24 to act as the legal connectivity provider. Room codes and pricing rate plans are systematically mapped between the systems.

  4. 4

    Dry-Run Simulation & Interoperability Diagnostic

    Pre-launch environment diagnostics. We deploy a "fake" test booking through the OTA platform, confirming the Webhook bounces the correct cryptographic signatures through Render, hitting MongoDB, and rendering live in the React UI.

  5. End-User Operational Handoff

    Generation of the Master Admin credentials. We log out of all developer access. Client takes total, autonomous control of the repository, servers, and the CRM application.
